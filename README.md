# PrayerTimes

This application should allow the user to view the daily prayer times based on
location and selected calculation method. The user should be able to view today and
upcoming prayer times for a week and display a countdown timer for the next prayer
time.
The user should also be able to view the Qibla direction on the map based on his
location.
As an additional point, the app can display the live direction of the Qibla based on
the gyroscope sensor.
